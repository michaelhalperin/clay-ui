# Tree View

Expandable file tree with selection.

## Import

```tsx
import { FileTree, type TreeNode } from 'clay-ui'
```

## Basic usage

```tsx
<FileTree />
```

## Exports

- `FileTree`
- `TreeNode`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `TreeNode` | interface | — | id, label, icon?, children? |
