# Navbar

Responsive marketing navbar patterns: default, centered, and transparent over hero sections.

> **Showcase component** — a pre-built demo layout with sample data. Use it for reference or copy patterns into your app. Open the [live showcase](/showcase/) to interact with it.

## Import

```tsx
import { NavbarShowcase } from 'clay-ui'
```

## Basic usage

```tsx
import { NavbarShowcase } from 'clay-ui'

function Example() {
  return <NavbarShowcase />
}
```
