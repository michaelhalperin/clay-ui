# Sortable List

Drag-to-reorder lists with `useDragSort` hook.

## Import

```tsx
import { useDragSort, type Item } from 'clay-ui'
```

## Basic usage

```tsx
const { items, onDragStart, onDragOver, onDrop } = useDragSort(initial)
```

## Exports

- `useDragSort`
- `Item`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `Item` | interface | — | Requires id: string |
