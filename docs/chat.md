# Chat

Messaging window and contact list layouts.

## Import

```tsx
import { ChatWindow } from 'clay-ui'
```

## Basic usage

```tsx
<ChatWindow />
```

## Exports

- `ChatWindow`
- `ContactList`
- `Message`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `Message` | interface | — | Exported message shape: id, text, sender, time, avatar |
