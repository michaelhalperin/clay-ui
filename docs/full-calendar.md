# Full Calendar

Month calendar with events.

## Import

```tsx
import { type CalEvent } from 'clay-ui'
```

## Basic usage

```tsx
const events: CalEvent[] = [{ id, title, date, color }]
```

## Exports

- `CalEvent`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `CalEvent` | interface | — | id, title, date, color?, time? |
