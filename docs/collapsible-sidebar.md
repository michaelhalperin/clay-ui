# Collapsible Sidebar

Expandable app sidebar navigation.

## Import

```tsx
import { type NavItem } from 'clay-ui'
```

## Basic usage

```tsx
const nav: NavItem[] = [{ id, label, icon, badge?, children? }]
```

## Exports

- `NavItem`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `NavItem` | interface | — | id, label, icon, badge?, children? |
