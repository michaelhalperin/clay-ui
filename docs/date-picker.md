# Date Picker

Single date, range, and inline calendar pickers.

## Import

```tsx
import { SinglePicker } from 'clay-ui'
```

## Basic usage

```tsx
<SinglePicker label="Start date" />
```

## Exports

- `SinglePicker`
- `RangePicker`
- `InlineCalendar`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | string | — | Field label (`SinglePicker`, `RangePicker`) |
