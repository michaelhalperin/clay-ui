# Carousel

Three carousel patterns: fullscreen slides, horizontal metric cards, and thumbnail strip navigation.

## Import

```tsx
import { SlideCarousel, CardCarousel, ThumbnailCarousel } from 'clay-ui'
```

## Basic usage

```tsx
import { SlideCarousel } from 'clay-ui'

function Example() {
  return <SlideCarousel />
}
```

## Exports

- `SlideCarousel`
- `CardCarousel`
- `ThumbnailCarousel`

_See component source for full typings._

## Notes

Each variant ships with demo content and autoplay. Fork the component to accept your own `slides` or `items` array.
