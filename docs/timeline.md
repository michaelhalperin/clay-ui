# Timeline

Vertical and compact event timelines.

## Import

```tsx
import { VerticalTimeline, type TimelineEvent } from 'clay-ui'
```

## Basic usage

```tsx
<VerticalTimeline events={events} />
```

## Exports

- `VerticalTimeline`
- `CompactTimeline`
- `TimelineEvent`

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `TimelineEvent` | interface | — | id, title, time, description?, icon?, color? |
